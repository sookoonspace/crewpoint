# Glossary

CrewPoint serves any event type and size, so code uses only these general terms. Event-specific words live in template data, and a CI guardrail enforces this (Req 2 of [Stage 1](https://github.com/sookoonspace/crewpoint/issues/44)).

## Terms

- **Event:** The whole occasion.
- **Organizer:** Who owns an event, either a person or an organization.
- **Member:** A login with a role in an event.
- **Participant:** A person attending an event, with or without a login.
- **Group:** People handled together.
- **Category:** A pricing or eligibility class.
- **Session:** Anything on the schedule.
- **Crew:** A working sub-team.
- **Registration:** A group's sign-up.
- **Custom field:** A question the organizer defines.
- **Pass:** A token that proves entry.
- **Charge:** What is owed.
- **Payment:** What is paid.
- **Contribution:** Money or goods offered.
- **Goal:** What contributions fund.
- **Update:** A live change sent to everyone.
- **Incident:** A reported problem.
- **Audience:** A saved set of recipients.

## How each event type uses them

These words appear only in template data and labels, never in code.

| **Group** | Family | Team | Foursome | Guest party | Household |
